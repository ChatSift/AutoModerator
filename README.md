Legacy v2 of AutoModerator. Out of use since September 2026. The new version is no longer open.

For a bit of history, `ChatSift/AutoModerator` eventually evolved into a giant monorepo, absorbing `ChatSift/AMA`,
`ChatSift/ModMail`, `ChatSift/Social`, `ChatSift/stack`, `ChatSift/caddy`, etc and being renamed to `ChatSift/chatsift`.

The `AutoModerator` codebase still found a home within the `v1` and `v2` branches of that repo, which are now deleted
and pushed to this *new* `ChatSift/AutoModerator` to preserve the once-open source code.
